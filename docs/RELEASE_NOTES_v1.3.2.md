# Hello Solar Planner 1.3.2

Equipment pricing and comparisons are now easier to review.

- Equipment sections show quantity × unit price = line total, with reference prices, user quotations and unverified allowances clearly identified.
- Each system option shows whether its equipment is generated or manually edited, its installed solar capacity, and an expandable cost breakdown.
- **Calculate regenerates equipment for both options**, replacing edited quantities and capacities. Entered quotations remain saved; review warnings appear when the associated equipment changes.
- Selecting a different named product uses its reference price. Use **Use reference price** to remove an individual quotation.
- Custom capacities without a matching reference retain an explicitly unverified allowance; prices are not scaled from watts or battery capacity.
- PDF and CSV reports include the same price basis and quotation review information as the dashboard.
- Pricing guidance now describes indicative African market planning estimates. The optional ±10% budgeting assumption does not change totals and is separate from contingency.

Existing saved projects remain supported. Before using Calculate on a manually edited plan, save or export any equipment arrangement you want to retain.

The partner release is `v1.3.2`; the Project Hello World hosted release is `v1.3.2-phw`.
